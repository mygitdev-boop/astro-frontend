# Astro BhavishyaAI -- Flutter App Setup

## What's here
This folder has the app's Dart source code (`lib/`) and dependency list
(`pubspec.yaml`), but NOT the platform folders (android/, ios/, etc.) --
those get generated by Flutter itself.

## Setup steps (run these on your Mac, once Flutter finishes installing)

### 1. Confirm Flutter is ready
```bash
flutter doctor
```

### 2. Create a fresh Flutter project
Navigate to wherever you want the project to live (NOT inside this
astro-frontend folder), then:
```bash
flutter create astro_bhavishya_ai
cd astro_bhavishya_ai
```
This generates the full project structure, including android/ and ios/
folders that Flutter needs to actually build and run the app.

### 3. Replace the generated lib/ and pubspec.yaml with these
Delete the `lib` folder and `pubspec.yaml` that `flutter create` just
generated, and copy this project's `lib/` folder and `pubspec.yaml` in
their place:
```bash
rm -rf lib pubspec.yaml
# then copy in the lib/ folder and pubspec.yaml from astro-frontend/
```

### 4. Install dependencies
```bash
flutter pub get
```

### 5. Run it
With a simulator open (iOS Simulator via Xcode, or an Android emulator via
Android Studio), or a physical phone connected:
```bash
flutter run
```

## What's built so far
- **Onboarding flow**: language selection -> name/phone -> birth details -> generates Kundli
- **Home feed**: greeting, energy score, today's highlights (star ratings), current dasha,
  lucky elements, quick questions, recommended items, continue-chat -- all wired to the
  live `/home-feed` endpoint
- **Kundli screen**: chart summary chips + the step-by-step AI explanation
- **Rashifal screen**: Today/Week/Month/Year tabs, wired to the cached `/rashifal` endpoint
- **Chat screen**: quick-question chips by category, free-form chat, shows remaining
  free questions/day

## Known gaps to fix before this is launch-ready
1. **No persistent login** -- `UserSession` (in `lib/services/user_session.dart`) is
   in-memory only. Add the `shared_preferences` package and persist `userId` so users
   don't have to re-enter everything on every app restart.
2. **Latitude/longitude entry is manual** -- the birth details form asks users to type
   coordinates directly, which nobody will know offhand. Before shipping, replace this
   with a place autocomplete (Google Places API) that resolves a typed city name to
   lat/long/timezone automatically.
3. **No OTP verification** -- phone number is currently just a text field with no
   verification step. The original plan calls for Firebase Auth with OTP; that's not
   wired in yet.
4. **No payment UI** -- the backend's Razorpay endpoints exist, but there's no
   Starter/Lifetime upgrade screen in the app yet.
5. **No AdMob integration** -- banner/interstitial ad placements aren't in the UI yet.
